# Personal Portfolio - Web Piscine Capstone

## Description
This is my Capstone project for the Web Piscine (Project 04). It is a fully responsive and interactive personal portfolio website built entirely from scratch without using any external frameworks, templates, or UI libraries (no Bootstrap, no Tailwind). It represents my authentic digital presence as a Translation Graduate and Web Developer.

## Features
- **Semantic HTML5** structure with a clean separation of concerns.
- **CSS3 Flexbox** & **Media Queries** for a seamless, mobile-responsive layout.
- **Interactive Theme Switcher:** JavaScript-powered Dark/Light mode toggle utilizing `classList.toggle`.
- **Smooth Scrolling** & **Sticky Navbar** for an enhanced User Experience (UX).
- **Custom CSS Variables (:root)** for centralized and maintainable color theming.

## Files Included
- `index.html`: The main structure and content.
- `style.css`: The styling, layout, and responsive design rules.
- `script.js`: The DOM manipulation and event-driven interactivity.
- `assets/`: Directory containing project images (e.g., profile photo).
- `README.md`: Project documentation.

## How to Run
Simply open the `index.html` file in any modern web browser. No local server or build tools are required.
